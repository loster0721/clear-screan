# 清屏 Clear Screen

帮助解决安卓手机应用开屏广告问题：自动识别「跳过」按钮并点击、拦截广告跳转。本仓库包含优化后的完整源码与发布包。

## 优化内容（v1.3.0-opt）

- **拦截速度**：单次扫描内存分配减少 55%~65%；冷启动主线程开销清零（后台预热）
- **拦截精准度**：4 处防误杀收紧（盲点手势、面板控件、中文邻接 ad 边界、导航名单）
- **内存卫生**：修复无障碍节点树从不回收的问题
- **关键修复**：Android 15 手势校验导致的「无障碍服务故障」崩溃（Path bounds must not be negative）

## 获取

在 Releases 页面下载：

- `清屏-优化源码与报告.zip` —— 完整 Android 工程源码 + 4 份诊断/修复报告
- `清屏v1.3.0-拦截优化修复版（推荐）.apk` —— 真机验证通过的安装包（debug 签名，仅供测试）

## 使用注意

安装后需在系统设置中开启无障碍服务；若更换签名安装，请在无障碍设置中关闭再重新开启。
